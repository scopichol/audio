# Інструкція з використання системи аналізу вимови

## Доступні скрипти

### 1. `test_simple.py` - Базова діагностика
Перевіряє чи всі компоненти системи працюють правильно.
```bash
python test_simple.py
```

### 2. `test_asr_only.py` - Тест ASR без запису
Тестує розпізнавання мовлення на існуючому аудіо файлі.
```bash
python test_asr_only.py
```

### 3. `test_step_by_step.py` - Покроковий режим
Інтерактивний режим з паузами між етапами для детального контролю.
```bash
python test_step_by_step.py
```

### 4. `test_phonem2.py` - Основний скрипт
Повний автоматичний режим з записом та аналізом.
```bash
python test_phonem2.py
```

## Процес використання

### Крок 1: Перевірка системи
```bash
python test_simple.py
```
**Результат:** Має показати ✅ для всіх компонентів

### Крок 2: Тест ASR (опціонально)
```bash
python test_asr_only.py
```
**Результат:** Аналіз існуючого аудіо файлу

### Крок 3: Запуск основної програми
**Для досвідчених користувачів:**
```bash
python test_phonem2.py
```

**Для покрокового контролю:**
```bash
python test_step_by_step.py
```

## Що робить програма

1. **Перевірка системи** - Діагностує доступність всіх компонентів
2. **Підготовка тексту** - Завантажує або створює референсний текст
3. **Генерація аудіо** - Створює референсний аудіо через TTS (якщо потрібно)
4. **Відтворення зразка** - Програє референсний аудіо для прослуховування
5. **Запис** - Записує ваш голос (6 секунд)
6. **Розпізнавання** - Транскрибує ваш запис через WhisperX
7. **Вирівнювання** - Синхронізує слова з часовими мітками
8. **Аналіз фонем** - Порівнює еталонні та розпізнані звуки
9. **Створення звітів** - Генерує графіки, таблиці та JSON файли

## Можливі проблеми та рішення

### "Програма зависає"
- Використовуйте `test_step_by_step.py` для покрокового виконання
- Перевірте інтернет з'єднання (для gTTS)

### "Помилка мікрофону"
- Перевірте підключення мікрофону
- Надайте дозвіл на використання мікрофону

### "Модель не завантажується"
- Перевірте доступний простір на диску
- Можливо потрібно змінити MODEL_NAME на "base.en"

### "TTS не працює"
- Встановіть додаткові бібліотеки: `pip install gtts pydub pyttsx3`
- Перевірте інтернет з'єднання для gTTS

## Налаштування

### Зміна референсного тексту
Відредагуйте файл `sentences/sentence_1.txt`

### Зміна тривалості запису
Змініть `SECONDS = 6` в скрипті на потрібне значення

### Зміна моделі WhisperX
Змініть `MODEL_NAME = "small.en"` на:
- "base.en" (швидше, менш точно)
- "medium.en" (повільніше, точніше)
- "large-v3" (найточніше, найповільніше)

## Інтерпретація результатів

### PER (Phone Error Rate)
- 0.0 = ідеальна вимова
- 0.1 = 10% помилок у звуках
- 0.3+ = потрібно поліпшувати вимову

### WER (Word Error Rate)
- 0.0 = всі слова розпізнані правильно
- 0.1 = 10% слів розпізнані неправильно

### Матриця плутанин
Показує які звуки плутаються між собою

### Графік порівняння
Відображає еталонні та розпізнані звуки в IPA нотації
