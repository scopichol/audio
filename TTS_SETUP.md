# Налаштування Text-to-Speech (TTS) для генерації аудіо

Якщо референсний аудіо файл відсутній, система автоматично спробує згенерувати його з тексту за допомогою TTS. Для цього потрібно встановити одну з наступних бібліотек:

## Варіант 1: gTTS (Google Text-to-Speech) - Рекомендовано

```bash
pip install gtts pydub
```

**Переваги:**
- ✅ Високоякісний голос Google
- ✅ Багато мов підтримується
- ✅ Природний звук

**Недоліки:**
- ❌ Потребує інтернет-з'єднання
- ❌ Залежить від Google API

## Варіант 2: pyttsx3 (Офлайн TTS)

```bash
pip install pyttsx3
```

**Переваги:**
- ✅ Працює офлайн
- ✅ Кросплатформенний
- ✅ Налаштування голосу та швидкості

**Недоліки:**
- ❌ Менш природний звук
- ❌ Обмежений вибір голосів

## Варіант 3: eSpeak (Linux/macOS)

### Linux:
```bash
sudo apt-get install espeak
# або
sudo yum install espeak
```

### macOS:
```bash
brew install espeak
```

**Переваги:**
- ✅ Легкий та швидкий
- ✅ Багато мов
- ✅ Відкритий код

**Недоліки:**
- ❌ Роботизований звук
- ❌ Не працює на Windows без додаткових налаштувань

## Використання в коді

Система автоматично спробує використати доступні TTS движки в наступному порядку:

1. **gTTS** (якщо є інтернет та встановлено gtts + pydub)
2. **pyttsx3** (якщо встановлено)
3. **espeak** (якщо встановлено в системі)

Якщо жоден варіант не працює, система продовжить роботу без референсного аудіо.

## Приклад згенерованих файлів

```
sentences/
├── sentence_1.txt          # Текст для вимови (створюється автоматично)
└── sentence_1.wav          # Згенероване аудіо (створюється автоматично)
```

## Налаштування якості

Для **gTTS**:
- Автоматично використовується найкраща якість Google
- Конвертується з MP3 у WAV для сумісності

Для **pyttsx3**:
- Швидкість: 150 слів за хвилину
- Гучність: 90%
- Автоматичний вибір англійського голосу

Для **espeak**:
- Швидкість: 150 слів за хвилину
- Мова: англійська (en)

## Рекомендації

1. **Для найкращої якості**: Використовуйте gTTS з інтернет-з'єднанням
2. **Для офлайн роботи**: Встановіть pyttsx3
3. **Для мінімальних залежностей**: Використовуйте espeak (Linux/macOS)

## Приклад встановлення (рекомендований)

```bash
# Встановлення всіх необхідних залежностей
pip install gtts pydub pyttsx3

# Для Linux також встановіть espeak як backup
sudo apt-get install espeak
```
