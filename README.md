## Ціль проекту:
розробити застосунок для занурення у вивчення іноземної мови.  
навчання в стилі  дитини. Дитина повторює речення за вчителем. Вчитель виправляє помилки вимови.  
З вивчених речень вчитель формує словник і в майбутньому може створювати діалоги з учнем виправляючи помилки в процесі діалогу  
ціль роботи дослідити ідею і визначити чи має вона практичний сенс.  

## Інструкція для запуску:
встановити requirements.txt  
python test_phonem2.py  
при потребі змінити тренувальну фразу змінити змінну у файлі  
доступні варіанти sentence_1 - sentence_10  
в каталозі sentence лежать пари файлів аудіо та текст  
REFERENCE_NAME = "sentence_1"  # Назва референсного файлу  

## Алгоритми і моделі
wisperx - для ASR з функцією Forced Alignment  
g2p - для створення фонем з тексту  
алгоритм Левенштайн - для порівняння фонем
